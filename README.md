# OCS 自建 AI 题库（精简版）

自建的题库服务，替代[OCS网课助手](https://github.com/ocsjs/ocsjs)默认的收费题库。自行接入DeepSeek大模型答题，价格极低。

答案可缓存在本地，拥有web可视化界面，能够快捷配置API，清除API，提供题库配置指引，能够开启题库缓存与关闭，开启可以避免重复搜题。但是不建议开启，可以删除已缓存题目，方便管理

**不需要懂编程，也不需要 pip 安装任何东西以及环境依赖。** 按下面五步走完就能用。

```
OCS 抓到题目 ──> 本地查缓存 ──有──> 直接返回答案（不花钱）
                      │
                      └─没有─> 问 DeepSeek ──> 存下来 ──> 返回答案
```

---

## 开始之前

要准备三样东西：

| 东西 | 说明 |
|---|---|
| 一台 Windows 电脑 | 本教程按 Windows 写 |
| Python | 免费的运行环境，第 1 步装 |
| DeepSeek 的 API Key | 一长串 `sk-` 开头的字符，要花几块钱 |

---

## 第 1 步：装 Python

1. 打开 <https://www.python.org/downloads/>，点最上面那个黄色的 **Download Python** 按钮。
2. 双击下载好的安装包。
3. **安装界面最下面有个勾选框 `Add Python to PATH`，一定要勾上。**
   这是唯一容易翻车的地方，不勾的话后面双击启动会提示找不到 Python。
4. 点 `Install Now`，等它装完，点 `Close`。

**验证一下**：按键盘 `Win + R`，输入 `cmd` 回车，会弹出一个黑窗口。在里面输入：

```
python --version
```

出现 `Python 3.x.x` 就对了。

如果提示「不是内部或外部命令」，说明第 3 步没勾。最简单的办法是重新运行安装包，
选 `Uninstall` 卸掉，再装一次，这次记得勾。

---

## 第 2 步：拿一个 API Key

1. 打开 <https://platform.deepseek.com>，用手机号注册登录。
2. 左边菜单点「充值」，充 10 元，或自定义。答完一门课通常几毛钱，10 元能用很久。
3. 左边菜单点「API keys」，再点「创建 API key」，随便起个名字（比如 `ocs`），确定。
4. 复制出来的那串字符，**以 `sk-` 开头**。

**这个 Key 只显示这一次**，关掉窗口就再也看不到了。先粘到记事本里存着。

---

## 第 3 步：填配置

1. 双击文件夹里的 `启动.bat`。
2. 第一次运行它会自己生成一个 `.env` 文件，然后提示你去填，按任意键把这个窗口关掉。
3. 找到刚生成的 `.env`，右键 →「打开方式」→「记事本」。
4. 找到这一行：

   ```
   DEEPSEEK_API_KEY=
   ```

   把刚才的 Key 粘到等号右边，变成：

   ```
   DEEPSEEK_API_KEY=sk-你的那一长串
   ```

5. **等号右边不要加引号，不要留空格。** 加了引号服务会认不出这个 Key。
6. 保存（`Ctrl + S`），关掉记事本。

---

## 第 4 步：启动

再双击一次 `启动.bat`。看到这样的输出就是成功了：

```
==========================================================
  OCS 自建 AI 题库（精简版 · 零依赖）
==========================================================
  [OK] 模型      : deepseek-chat
  [OK] API 地址  : https://api.deepseek.com/v1
  [OK] 端口      : 8000
  [OK] 数据库    : C:\...\OCS-AI-Question-Bank\cache.db
       本次新建空库（第一次运行会出现这种情况）
  [!] 接口令牌  : 未启用
  ...
  控制台       http://127.0.0.1:8000/
```

看两个地方：

- 出现 `[OK] 模型` → Key 已经读到了。如果这里是 `[!] 未配置 DEEPSEEK_API_KEY`，
  回第 3 步检查 Key 有没有粘对。
- 出现 `[OK] 端口 : 8000` 且没有报错 → 服务起来了。

`[!] 接口令牌 : 未启用` 不影响使用，只是提醒你同局域网的人可能盗用额度。
想关掉这个提醒就在 `.env` 里设一个 `API_TOKEN`，OCS 里填同一个值。

**这个黑窗口不要关。** 关了服务就停了，OCS 会连不上。
刷课期间让它一直开着，最小化就行。

浏览器打开 <http://127.0.0.1:8000/> 能看到控制台页面，说明服务正常。

---

## 第 5 步：接到 OCS

OCS 网课助手是另一个独立的浏览器脚本，本项目不包含它。

- 官网：<https://ocsjs.com>
- 源码：<https://github.com/ocsjs/ocsjs>
- 文档：<https://docs.ocsjs.com>

按它官网的说明装好（需要先装油猴 Tampermonkey 或脚本猫 ScriptCat，再导入 OCS 脚本）。
装完打开 OCS 面板，然后：

1. 回到本项目的控制台 `http://127.0.0.1:8000/`。
2. 往下找到「**接入 OCS**」区块，点里面的「复制」按钮，配置就复制到剪贴板了。
3. 在 OCS 面板里打开「设置」→「题库配置」→「题库配置填写/修改区」。
4. 把复制的内容粘进去，保存配置。
5. 建议关闭题库缓存功能。（避免错误答案堆积）

回到网课页面，OCS 就会自动把题目发到本服务来。

> 想手动填的话，题库地址是 `http://127.0.0.1:8000/query`，
> 但那段 JSON 里的 `type` 必须是 `GM_xmlhttpRequest`，用别的会请求不通。

## 怎么确认真的通了

按顺序看这三个：

1. 控制台「手动测试」框里随便输一道题（比如「1+1 等于几」），点提交 →
   **能出答案**，说明 Key 和服务都正常。
2. 开始刷课，盯控制台左上角「**累计查询**」→ **这个数字在涨**，说明 OCS 真的在请求你。
3. 「**缓存命中**」跟着涨 → 重复的题走了缓存，没重复花钱。

第 2 步不涨，就别在答题逻辑上找原因了，问题在 OCS 那边（题库没启用、地址写错、
或者浏览器拦了本地请求）。

## 出问题了

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击 `启动.bat` 窗口一闪就没 | 找不到 Python | 回第 1 步，确认勾了 `Add Python to PATH`，用 `python --version` 验证 |
| 提示 `[!] 未配置 DEEPSEEK_API_KEY` | `.env` 没填或填错 | 打开 `.env`，看 Key 是否粘在等号右边、有无引号空格 |
| 提示端口被占用 | 8000 被别的程序占了 | 打开 `.env`，把 `PORT=8000` 改成 `8001`，重启；OCS 里的地址也改成 8001 |
| 「累计查询」一直不涨 | 请求没到服务 | 查 OCS 题库是否启用、地址端口对不对 |
| 「最近请求」全是「空题」 | OCS 传来的题目是空的 | 检查 OCS 题库配置里的 `${title}` 有没有被改掉 |
| 「最近请求」全是「跳过」 | 抓到的是课件正文不是题 | 正常，这是拦截，不浪费额度 |
| 「最近请求」全是「失败」 | Key 无效或余额不足 | 去 DeepSeek 后台看余额，或在控制台点「保存并测试」 |
| 页面上选项勾了，面板说没选 | 答案格式没对上 | 本项目已处理，仍有问题把那道题发给我看 |
| 改了代码，答案还是旧的 | 三层缓存 | 见下面「缓存」 |

## 关于缓存

答过的题会存进本地文件 `cache.db`，下次遇到同样的题直接返回，不再调模型。
这个文件可以随时删，删了下次会自动重建，只是统计数字会归零。

**注意 OCS 自己也有一层缓存。** OCS 开着「题库缓存」时，答过的题直接从浏览器本地取，
根本不会再来问本服务。所以你会发现「累计查询」不涨——这不是服务坏了。

要让 OCS 重新问，去 OCS 面板：**通用 → 拓展应用 → 题库缓存 → 清空**。

## 常见问题

**要花多少钱？**
DeepSeek 按字数计费，截止2026/10/23`deepseek-chat` 输入约 0.27 元/百万字，输出约 1.1 元/百万字。
一门课的题加起来通常几万字，也就是几毛钱。缓存命中的题不花钱。

**安全吗？**
Key 只存在你电脑上的 `.env` 文件里，不会上传到任何地方。
`.gitignore` 已经把它排除，不会被提交到代码仓库。
服务默认监听 `0.0.0.0`，同局域网的人知道你 IP 就能白用你的额度，
所以建议在 `.env` 里设一个 `API_TOKEN`（随便一串字符），OCS 里填同一个值。

**能换别的模型吗？**
能。`.env` 里 `DEEPSEEK_MODEL` 改 `deepseek-reasoner` 更准但更慢更贵。
用本地模型（Ollama 之类）的话，把 `DEEPSEEK_BASE_URL` 改成它的地址即可。

**黑窗口能关吗？**
不能。它是服务本身，关了 OCS 就找不到题库。不想让它占任务栏就最小化。

**这个和 OCS 官方题库什么关系？**
没关系。这是一个替代品，用你自己的 Key 答题，钱直接付给 DeepSeek，
不经过任何第三方题库。

## 想改代码的话

```
run.py                启动入口
server/               后端
├── config.py           读/写 .env、prompt
├── store.py            SQLite 缓存 + 统计
├── llm.py              调模型、清洗答案
├── matching.py         答案对齐到选项
├── detector.py         非题目识别
├── service.py          一次查询的流程
└── api.py              路由 + 静态文件
web/                  前端（纯静态，改样式只动 style.css）
docs/matching.md      和 OCS 适配的细节：为什么这么处理
```

依赖是单向的，不会循环导入：

```
api -> service -> llm / matching / detector / store -> config
```

**改配置别写 `from .config import API_KEY`**，那是快照，网页上存了新 Key 也不生效，
要用 `config.API_KEY` 这种属性访问。

### 接口

| 接口 | 用途 |
|---|---|
| `GET/POST /query` | OCS 调用的答题接口，参数 `title` / `options` / `type` / `token` |
| `GET /api/status` | 控制台用的汇总数据 |
| `GET /api/cache` | 缓存题目列表，参数 `q`（关键词）/ `limit` |
| `POST /api/config` | 保存或清除配置 |
| `GET /health`、`GET /stats` | 健康检查、统计数字 |

`/query` 返回 `{"code":1,"data":{"question":"...","answer":"..."}}`，
`code=0` 表示没答上，OCS 会自动回退到其他题库，不会中断刷课。
